## 方案 A：使用国内镜像站密钥（推荐）
```
curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
```


3. 配置国内镜像软件源
由于官方源连接困难，请将软件源修改为阿里云镜像站：
```
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://mirrors.aliyun.com/docker-ce/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```


4. 安装 Docker 引擎
更新索引并安装组件：
```sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y
```
5. 配置镜像加速器（重要）
安装完成后，为了确保拉取 Docker 镜像（如 nginx, mysql）不卡顿，建议配置镜像加速器。编辑或创建配置文件：
```sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://hub-mirror.c.163.com",
    "https://docker.m.daocloud.io"
  ]
}
EOF```

6. 重启服务
使配置生效并设置开机自启：
```sudo systemctl daemon-reload
sudo systemctl restart docker
sudo systemctl enable docker```


在容器化开发领域，您提到的“Docker Toolkit”通常指代 **NVIDIA Container Toolkit**。该工具包允许 Docker 容器调用宿主机的 NVIDIA GPU 资源，是进行 AI 训练、深度学习及高性能计算（如您之前提到的 openpilot 仿真）的必要组件。

以下是在 Ubuntu 24.04 上安装 NVIDIA Container Toolkit 的标准专业流程：

### 1. 前置条件确认
在安装工具包之前，请确保您的系统中已安装 NVIDIA 驱动程序。您可以通过以下命令验证：
```bash
nvidia-smi
```
如果未显示显卡信息，请先通过 `sudo ubuntu-drivers install` 安装推荐驱动。

### 2. 配置 NVIDIA Container Toolkit 存储库
由于网络环境可能存在限制，我们将配置 NVIDIA 官方的存储库。

**导入 GPG 密钥：**
```bash
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
```

**添加软件源列表：**
```bash
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
```

### 3. 安装 NVIDIA Container Toolkit
更新软件包索引并执行安装：
```bash
sudo apt-get update
sudo apt-get install -y nvidia-container-toolkit
```

### 4. 配置 Docker 运行时
安装完成后，需要配置 Docker 以识别并使用 NVIDIA 运行时环境：

```bash
sudo nvidia-ctk runtime configure --runtime=docker
```
该命令会自动修改 `/etc/docker/daemon.json` 文件，添加必要的运行时配置。

### 5. 重启 Docker 服务
应用配置更改：
```bash
sudo systemctl restart docker
```

### 6. 验证 GPU 容器支持
运行一个测试容器，验证 Docker 是否能够正确调用 GPU。执行以下命令：
```bash
sudo docker run --rm --runtime=nvidia --gpus all nvidia/cuda:12.0.1-base-ubuntu22.04 nvidia-smi
```
**结果判定**：如果输出结果中显示了您的显卡型号及显存使用情况，则表示安装成功。

### 常见问题说明：
*   **网络连接失败**：如果您在执行 `curl` 时再次遇到 `SSL_ERROR_SYSCALL`，这通常是因为 GitHub 相关域名（nvidia.github.io）访问受限。建议在终端中配置代理，或多次尝试。
*   **Docker Desktop 用户**：如果您使用的是 Docker Desktop for Linux 而非 Docker Engine，配置方式略有不同，通常 Docker Desktop 已内置部分支持，但仍需确保宿主机驱动版本匹配。
