# 大众速腾车型适配可行性文档

## 1. 概述

本文档分析如何为24款大众速腾（无ACC）添加openpilot车型适配，实现车道显示和预测功能（不进行控制）。

## 2. 车型识别机制分析

### 2.1 openpilot车型识别流程

```
CAN指纹采集 → 固件版本查询 → VIN码解析 → 车型匹配 → 参数配置
```

### 2.2 关键识别要素

1. **CAN指纹 (fingerprint.json)**
   - CAN消息ID及数据长度
   - 用于初步车型筛选

2. **固件版本 (FW_VERSIONS)**
   - ECU固件版本号
   - 用于精确车型匹配

3. **VIN码信息**
   - WMI (世界制造商识别码)
   - 底盘代码 (chassis_codes)

## 3. 大众速腾适配方案

### 3.1 数据采集需求

#### 3.1.1 CAN指纹采集
```bash
# 使用现有工具采集CAN数据
python tools/vw/cabana_csv_to_fingerprint.py
```

需要采集的关键CAN消息：
- 转向角度传感器
- 车速信息
- 车道线检测相关
- 仪表盘状态

#### 3.1.2 固件版本采集
```python
# 需要查询的ECU
required_ecus = {
    Ecu.engine: 0x7e0,      # 发动机控制单元
    Ecu.srs: 0x715,         # 安全气囊系统
    Ecu.eps: 0x712,         # 电动助力转向
    Ecu.fwdRadar: 0x757,    # 前向雷达（如有）
}
```

### 3.2 车型定义

#### 3.2.1 在values.py中添加速腾定义
```python
VOLKSWAGEN_SAGITAR_MK8 = VolkswagenMQBPlatformConfig(
    [
        VWCarDocs("Volkswagen Sagitar 2024", "24款大众速腾"),
    ],
    VolkswagenCarSpecs(
        mass=1400,           # 车重(kg) - 需实测
        wheelbase=2.69,      # 轴距(m) - 查规格书
        steerRatio=15.6,     # 转向比 - 需实测或查规格
    ),
    chassis_codes={"XX"},    # 底盘代码 - 从VIN获取
    wmis={WMI.SAIC_VOLKSWAGEN},  # 上汽大众
)
```

#### 3.2.2 在fingerprints.py中添加指纹数据
```python
CAR.VOLKSWAGEN_SAGITAR_MK8: {
    # 从采集的fingerprint.json复制数据
    (Ecu.engine, 0x7e0, None): [
        # 发动机ECU固件版本
    ],
    (Ecu.srs, 0x715, None): [
        # 安全气囊ECU固件版本  
    ],
    (Ecu.eps, 0x712, None): [
        # 转向ECU固件版本
    ],
    # 注意：无ACC车型可能没有fwdRadar
}
```

### 3.3 功能配置

#### 3.3.1 仅显示模式配置
```python
# 在interface.py的_get_params方法中添加
if candidate == CAR.VOLKSWAGEN_SAGITAR_MK8:
    # 仅显示模式，不进行控制
    ret.dashcamOnly = True
    ret.openpilotLongitudinalControl = False
    ret.pcmCruise = True
    ret.radarUnavailable = True  # 无雷达
    
    # 禁用所有控制功能
    ret.steerControlType = structs.CarParams.SteerControlType.none
    ret.lateralTuning.which = 'none'
```

## 5. 技术难点与解决方案

### 5.1 无ACC系统适配

**问题**: 速腾无ACC，缺少前向雷达和相关CAN消息

**解决方案**:
```python
# 在fingerprints.py中不包含fwdRadar
# 在interface.py中设置
ret.radarUnavailable = True
ret.openpilotLongitudinalControl = False
```

### 5.2 CAN网络架构识别

**问题**: 需要确定CAN网络拓扑结构

**解决方案**:
```python
# 通过检测特定消息判断网络位置
if any(msg in fingerprint[1] for msg in (0x40, 0x86, 0xB2, 0xFD)):
    ret.networkLocation = NetworkLocation.gateway
else:
    ret.networkLocation = NetworkLocation.fwdCamera
```
