# 环境搭建与容器部署

> 本文合并自「安装及编译」「容器发布」，按逻辑重组：开发机环境 → openpilot 编译
> → ARM64/Jetson 容器构建与发布 → JetPack 版本与升级 → Jetson 部署。

## 一、开发机环境（Ubuntu 24.04）

### 1. 安装 Docker（阿里云镜像源）

```bash
# 导入密钥
curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

# 配置国内源
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://mirrors.aliyun.com/docker-ce/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

镜像加速器：
```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://hub-mirror.c.163.com",
    "https://docker.m.daocloud.io"
  ]
}
EOF
sudo systemctl daemon-reload && sudo systemctl restart docker && sudo systemctl enable docker
```

### 2. 安装 NVIDIA Container Toolkit（GPU 容器支持）

前置：确认已装 NVIDIA 驱动（`nvidia-smi`；无则 `sudo ubuntu-drivers install`）。

```bash
# 密钥与源
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | \
  sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

# 安装 + 配置 Docker 运行时
sudo apt-get update && sudo apt-get install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker

# 验证
sudo docker run --rm --runtime=nvidia --gpus all nvidia/cuda:12.0.1-base-ubuntu22.04 nvidia-smi
```
> 若 `curl` 遇 `SSL_ERROR_SYSCALL`，多为 `nvidia.github.io` 访问受限，配代理或重试。

## 三、ARM64 / Jetson 容器构建与发布

构建流程：ARM 云主机（或 buildx）编译 → 镜像 → scp/pull 到 Jetson 运行（L4T + NVIDIA runtime）。

```bash
# 构建基础镜像与应用镜像
docker build --platform linux/arm64 -t openpilot-base-arm64 -f Dockerfile.openpilot_base .
docker build --platform linux/arm64 -t openpilot-arm64 -f Dockerfile.openpilot-arm64 .

# 本地调试运行（挂载源码 + ccache）
docker run -it --rm \
  -v /root/openpilot:/home/op/openpilot \
  -v ~/.ccache:/ccache \
  openpilot-arm64 bash
```

### raylib 依赖（UI 需要，aarch64 静态库）
```dockerfile
RUN apt-get update && apt-get install -y \
  build-essential g++ cmake git \
  libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libxext-dev \
  libxrender-dev libxfixes-dev libxkbcommon-dev libgl1-mesa-dev libegl1-mesa-dev \
  && rm -rf /var/lib/apt/lists/*

RUN git clone https://github.com/raysan5/raylib.git /tmp/raylib && \
    cd /tmp/raylib && git checkout 4.5.0 && \
    mkdir build && cd build && \
    cmake .. -DBUILD_SHARED_LIBS=OFF -DPLATFORM=Desktop && make -j$(nproc)

RUN mkdir -p third_party/raylib/aarch64/include && \
    cp /tmp/raylib/build/raylib/libraylib.a third_party/raylib/aarch64/ && \
    cp -r /tmp/raylib/src third_party/raylib/aarch64/include/raylib
```

### 发布与运行
```bash
docker tag openpilot-arm64:latest mindcont/openpilot-arm64:latest
docker push mindcont/openpilot-arm64:latest

docker run -it --rm --network host mindcont/openpilot-arm64:latest bash
```

已确认容器使用 NVIDIA runtime（`docker inspect openpilot-ui | grep Runtime` → `"Runtime": "nvidia"`），
Docker ↔ Jetson ↔ GPU 链路打通。

## 四、JetPack / Ubuntu 版本对照（2026-07 核对）

Jetson 端跑 L4T，Ubuntu 版本随 JetPack：

| JetPack | L4T | 设备端 Ubuntu | 内核 / CUDA | 备注 |
|---------|-----|--------------|-------------|------|
| 5.x | 35.x | 20.04 | 5.10 | 旧 |
| 6.x | 36.x | **22.04** | 5.15 / CUDA 12 | 生态成熟 |
| **7.0 / 7.2** | 38.2 / 39.2 | **24.04 LTS** | 6.8 / CUDA 13 | 最新，与本项目 24.04 对齐 |

- JetPack **7.2** 才把 24.04/CUDA 13 扩展到整个 **Jetson Orin** 系列 → Orin NX 可刷 24.04，
  与 `Dockerfile.openpilot-arm64`（基于 24.04）天然一致。
- 权衡：选 7.2 设备端与项目 24.04 一致，但生态很新、CUDA 13 需验证 tinygrad GPU 后端；
  选 6.2（22.04）生态成熟但与项目 24.04 有 glibc/依赖差异。openpilot 推理走自带 tinygrad，
  对 PyTorch wheel 依赖小。

### 6.x → 7.2 升级路径

**跨大版本不能 `apt upgrade`**（内核 5.15→6.8、bootloader/分区都变）。同大版本（6.2.1→6.2.2）
可改源 `apt full-upgrade` 原地升。前提：7.2 要求设备已有 6.x 代 UEFI/QSPI 固件。

| 方式 | 恢复模式 | host PC | 说明 |
|------|---------|--------|------|
| ① SDK Manager 重刷 | 需 RCM | 需(22.04/24.04) | 最常规，全量重刷清空设备 |
| ② ISO USB 安装器 | 否 | 否 | 7.2 新增，主要面向 devkit |
| ③ 镜像式 OTA | 否 | 否 | 原地升，**有 brick 案例，风险高** |

**推荐 ① SDK Manager 重刷**（当全新安装），生产设备勿用 ③ OTA。
> Orin NX 进 RCM 的针脚取决于载板，查 carrier 手册（一般短接 FC_REC + GND 再上电）。

升级前备份：
```bash
tar czf ~/orin_backup_$(date +%F).tar.gz \
  /data/params /data/media/0/realdata ~/openpilot/start_openpilot_orinnx.sh
rsync -avz orin:~/orin_backup_*.tar.gz ./
```

刷完 7.2 验证 checklist：
- [ ] tinygrad 用上 GPU（CUDA 13）：`DEV=CUDA` 跑 modeld 确认无 CPU fallback
- [ ] V4L2 双摄采集：`v4l2-ctl --list-devices`，单摄 `SINGLE_CAM=1` 跑通
- [ ] ARM64 容器在 24.04 + nvidia runtime 下能起
- [ ] manager 首次跑通（onboarding 由启动脚本跳过）
- [ ] 车道线出得来：订阅 `modelV2` 看 `laneLineProbs > 0.5`

## 五、Jetson 部署（systemd 开机自启）

`/etc/systemd/system/openpilot.service`：
```ini
[Unit]
Description=OpenPilot Docker (Jetson)
After=docker.service graphical.target
Requires=docker.service

[Service]
Restart=always
RestartSec=5
TimeoutStartSec=0
Environment=DISPLAY=:1
Environment=XDG_RUNTIME_DIR=/tmp/runtime-root
ExecStartPre=/usr/bin/xhost +local:docker
ExecStart=/usr/bin/docker run --rm --name openpilot \
  --network host --ipc host --runtime nvidia --privileged \
  -e DISPLAY=:1 -e XDG_RUNTIME_DIR=/tmp/runtime-root \
  -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
  -v /run/dbus/system_bus_socket:/run/dbus/system_bus_socket \
  -v /etc/machine-id:/etc/machine-id:ro \
  -v /data:/data \
  --device /dev/dri --group-add video \
  mindcont/openpilot-arm64:latest \
  /home/batman/openpilot/selfdrive/ui/ui
ExecStop=/usr/bin/docker stop openpilot

[Install]
WantedBy=graphical.target
```
```bash
sudo systemctl daemon-reload && sudo systemctl enable openpilot && sudo systemctl start openpilot
```

装车级能力现状：

| 模块 | 状态 | 说明 |
|------|------|------|
| JetPack / Ubuntu | ⚠️ 待定 | 6.2=22.04 / 7.2=24.04 |
| NVIDIA runtime | ✅ | 已确认 Runtime=nvidia |
| GPU 推理 (tinygrad) | ⏳ 需验证 | 目标 CUDA 版本上验证 |
| 摄像头采集 (V4L2) | ❌ 待实机 | 双摄同步/带宽，首跑建议 SINGLE_CAM=1 |
| CAN / panda | ❌ | 本项目纯视觉不控车，NOBOARD=1 |

后续：自动构建 / SSH / OTA 增量升级。
