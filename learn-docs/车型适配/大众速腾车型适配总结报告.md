# 大众速腾车型适配总结报告

## 📋 项目概述

本项目为24款大众速腾（无ACC）提供openpilot车型适配，实现车道显示和预测功能（不进行控制）。

## 🎯 实现目标

- ✅ 车道线检测与显示
- ✅ 行驶轨迹预测  
- ✅ 车辆状态监控
- ✅ 基础UI显示
- ❌ 纵向控制（ACC）- 车辆无此功能
- ❌ 横向控制（车道保持）- 仅显示模式

## 🔍 技术细节

### CAN消息映射
```python
# 关键CAN消息（需要实车验证）
{
    "0x1A0": 8,  # Bremse_1 - 制动信息
    "0x86": 8,   # LWI_01 - 转向角度
    "0xB2": 8,   # ESP_19 - ESP状态
    "0x6B8": 8,  # Kombi_03 - 仪表盘
    "0x30F": 8,  # SWA_01 - 方向盘按键
}
```

### ECU地址映射
```python
{
    Ecu.engine: 0x7e0,    # 发动机控制单元
    Ecu.srs: 0x715,       # 安全气囊系统
    Ecu.eps: 0x712,       # 电动助力转向
    # 注意：速腾无ACC，通常没有fwdRadar
}
```
